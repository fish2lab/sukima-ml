# 东方部分改成木刻画展风：目的、主线、取舍

## 目的

从 B 站短片点进来的人，先像逛画展一样把四幅作品看完，喜欢哪幅再进详情页选尺寸、装裱、下单。站点画面和片子第 2 段一致：暖白纸墙、木刻粗黑框、隙间从上往下扫过把名画换成东方版、展签翻出来。Studio Phantasm（`/ph`）不在范围内，外观一像素不变。

## 主线

1. **首页是一面画廊墙。** 开场一道隙间张开，升起 Logo 和「名画与东方的邂逅」；往下滚，镜头沿墙横移（桌面）或一幅幅竖排（手机），每幅画上隙间扫过；四幅看完，墙拉远；然后是 Endlessly 17 票据和四个入口。
2. **作品集页 `/sukima-ml` 是展厅里的讲解。** 八云紫从一道隙间里探出来当讲解员，立绘保持原色；讲解气泡改成片子第 5 段那种黑白漫画对话框。作品本身按原样显示。
3. **详情页负责卖。** 价格、尺寸、装裱、购买按钮只在详情页和购买页出现。
4. **其他页面（关于、微喷工艺、购买、联系、QQ 群、东方测试、版权、博客）** 统一换成纸墙 + 展签 + 木刻毛边，文字内容不改。

## 取舍

- 首页不写价格，按钮是「看这幅」进详情页：用少一步冲动下单，换画展的完整感和价格只在一处维护。（站主 2026-09-24 选定）
- 作品集页留八云紫：用整页唯一一处高饱和，换品牌辨识度和原有的点击讲解交互。（站主 2026-09-24 选定）
- 中文全部用霞鹜文楷屏幕版：用按需加载的字体分片（每页只下载用到的字，体积在验收时实测），换和片子一致的手写感。
- 首页和作品集页都展示同四幅画：首页是走一遍的画展，作品集是停下来听讲解，两处共用 `src/data/galleryData.ts`。

## 分工和验收

- 画风地基和组件：`src/components/woodcut/`，用法只看其中的 `README.md`。
- 各页面由各自的分支改，合并到 `woodcut-redesign`；验收由主会话在桌面 1440×900 和手机 390×844 两种尺寸下统一截图检查，另检查 `/ph` 不变。
- 不 push、不部署；站主看过后再决定合并进 main。
